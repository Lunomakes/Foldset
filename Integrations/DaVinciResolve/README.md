# Foldset · 达芬奇媒体夹

扩展随 Foldset App 携带，按需安装至当前用户的达芬奇脚本菜单。历史实机记录针对 DaVinci Resolve Studio 21.1 / macOS，免费版和其他版本尚未验证。

1. 在达芬奇媒体池左侧选中目标普通媒体夹（如 Master）。
2. 打开“工作区 → 脚本 → Foldset”，菜单中直接显示全部预设。
3. 点击预设名称即可创建，不再打开选择窗口或二次确认；成功静默，失败显示错误。

Foldset 1.2.1 保存模板后自动同步菜单（约 0.6 秒）。收起并重新打开达芬奇脚本菜单可看到最新项目。菜单项按模板唯一标识读取最新内容。旧选择入口已备份移出菜单，模板改名或删除后的旧菜单文件归档至 `~/Library/Application Support/Foldset/Resolve/MenuArchive`。

模板仍在 Foldset 中管理。每次运行重新读取 `~/Library/Application Support/XuXia/templates.json`，复用编号、起始值、位数和分隔符，不需要打开 Foldset。不会创建硬盘目录，不导入或移动素材。已有同名子媒体夹跳过，不删除或覆盖；中途失败保留已创建内容并报告数量。选择窗口打开后若项目或目标媒体夹变更，会停止创建。

开发者手动安装（旧流程，需要编译环境）：在项目目录执行 `python3 scripts/install-resolve.py`。仅安装 Foldset 自身脚本，覆盖前备份。入口放在用户 Library 下的 Resolve/Fusion/Scripts/Utility/Foldset，公共代码位于 Application Support/Foldset/Resolve。

## Finder 使用状态标记（2026-10-15）

入口：工作区 → 脚本 → Foldset → Finder 使用状态标记。

1. 选择全部时间线或当前时间线，点击扫描。范围仅限当前项目媒体池的源文件，扫描不改项目和源文件标签。
2. 核对结果，点击写入 Finder 标签：绿色已使用、灰色未使用候选、黄色待核实。保留原有标签，不移动或删除文件。同一项目再次标记会替换该项目上次状态，其他项目的标签保留。
3. 点击查看未使用候选，在 Finder 打开该项目／范围的精确标签搜索，便于手动整理。当前时间线未使用不代表其他时间线未使用；搜索依赖磁盘的 Spotlight 索引。查看清单可取得完整文件路径。
4. 当前窗口内可撤销最近一次标记，重新扫描不丢失撤销记录。关闭窗口后按钮状态不保留；每次写入前后的标签日志仍保存在 Application Support/Foldset/Resolve/UsageReports 的 tag-journal.json，必要时通过 foldset_tags.undo(日志路径) 恢复。撤销保留用户后来新增的标签，跳过文件替换或后续项目标签变化。

识别限制：Usage=0 不能单独证明未使用，实际时间线引用优先。扫描包含音视频轨道、备选镜头与可读取的嵌套时间线；遇到无法展开的复合／多机位、Fusion 或同步音频依赖时，将未确认文件标为待核实，不生成可删除判断。源文件离线、图片序列路径占位符和无独立源文件条目跳过。标记是扫描时的快照；剪辑变化后须重新扫描。

验证：10 项扫描／标签／撤销测试和 7 项原媒体夹检查通过。测试文件在真实 Finder 保存搜索中仅显示未使用文件，随后撤销全部 3 个测试标签。实际项目的全部时间线识别到 53 个已使用、117 个待核实、0 个未使用候选，另 10 个条目无可标记源文件。当前时间线识别到 37 个已使用、133 个待核实、0 个未使用候选。未向真实项目素材写入标签。已检查文字、按钮比例、对齐及截断。本机 Resolve 深色窗口已验证，其他系统外观／旧版 Resolve 尚未验证。

### 按状态直接筛选与批量移动

扫描完成后点击“素材列表…”，选择已使用、未使用候选、未导入或待核实，再按文件夹缩小范围。列表直接读取扫描结果，不依赖 Finder / Spotlight 索引；支持鼠标、Command / Shift 多选以及全选、取消选择。长路径可悬停查看。

选择文件后点“移动所选文件到…”，选目标目录，核对数量和路径后点“确认移动”。保留所选文件之间的相对目录结构和原标签。同名文件不覆盖，跨磁盘移动暂不支持。确认时重新扫描项目；扫描状态改变会要求重新扫描。移动、回收及恢复后自动重新扫描并更新各分类；重扫失败时保留仍存在文件的只读快照，禁用文件操作并提示重新扫描。

“恢复上次移动”按日志恢复最近一个未恢复完的批次。原位置被占用或目标文件已改变时跳过，避免覆盖。日志在 `~/Library/Application Support/Foldset/Resolve/MoveReports`。已导入素材移动后可能离线；不会自动重链接。未使用候选与未导入均不等于可安全删除；仅提供移到废纸篓，不提供永久删除。

验证：`python3 Tests/MoveTests.py`（10项，临时文件验证标签保留、冲突、变更、部分失败与恢复）；`python3 Tests/UsageTagsTests.py`（17项）；`python3 Tests/UsageWindowTests.py`（2项）。安装：`python3 scripts/install-resolve.py`，关闭已有 Foldset 脚本窗口后重新从菜单打开。无需重建原生 App。

### 移到废纸篓

素材列表选择文件后点“移到废纸篓…”，在弹出的达芬奇风格确认窗口中核对数量和影响，再点“移到废纸篓”。这调用 macOS FileManager.trashItem，不永久删除；不支持废纸篓的磁盘或权限错误会停止，绝不回退为直接删除。操作前重新扫描并校验文件身份；逐个记录结果，部分失败后需重新扫描。日志：`~/Library/Application Support/Foldset/Resolve/TrashReports`。恢复在 Finder 废纸篓操作，普通“恢复上次移动”不处理废纸篓。已导入素材移走会离线，其他项目引用不会自动更新。

旧开发者安装脚本需要 Xcode Command Line Tools（xcrun swiftc），编译 TrashFile.swift 到脚本支持目录。`python3 Tests/TrashTests.py` 的5项测试覆盖校验、系统拒绝和日志；未对用户素材执行删除验证。

确认和进度窗口使用达芬奇内置 UIManager，与素材列表保持一致。进度显示已处理/总数、百分比及当前文件，完成或失败后可关闭。窗口操作不使用原生 macOS 弹窗；只有底层移到废纸篓调用系统 FileManager。

### 未使用素材与媒体池联动清理

在“未使用候选”分类中选择文件并移到废纸篓，会同步清理当前项目媒体池的对应条目。执行前按全部时间线严格复扫（不忽略复合片段），仍有引用或依赖待核实会停止；项目导出备份成功后才移动文件。只移除成功回收文件对应的条目，文件回收失败则保留媒体池条目。其他分类不做媒体池联动。项目备份位于 `~/Library/Application Support/Foldset/Resolve/ProjectBackups`；Finder 放回文件不会自动恢复媒体池条目，必要时使用项目备份。不追溯清理历史离线条目。

素材列表支持右键单个文件 → 在 Finder 中显示。扫描前选择素材根文件夹后，点击“排除文件夹…”，按住 Command 多选不参与扫描的子文件夹，再点“应用排除”。排除包含后代目录，对四种分类均生效；清理后的自动重扫沿用排除规则。更换根目录或重新打开筛选窗口需重新设置排除项，已有 Finder 标签不会被自动清除。

## App 内按需安装（2026-10-16）

正式版入口：设置 → 扩展 → DaVinci Resolve。首次安装不会自动部署；普通文件夹模板可独立使用。安装后从 Resolve 的“工作区 → 脚本 → Foldset”进入。更新、修复或卸载前需退出 Resolve，完成后重新打开。

- 一个 App 包含 Python 脚本、菜单入口和预编译的 `FoldsetTrashFile`。编译只在构建机发生，用户不需要 Xcode；当前构建目标与主 App 一致，为 Apple Silicon / macOS 14+。
- 安装检查校验完整程序清单的 SHA-256、辅助程序执行权限和当前模板菜单，区分未安装、已安装、可更新、安装不完整／旧安装。文件检查不等于 Resolve 运行验证。
- 扩展独立版本写在 `scripts/bundle-resolve.sh` 中。扩展更新应递增版本；即使漏增，清单差异仍会提示更新。App 更新不会自动覆盖扩展，打开扩展设置页可查看状态。
- 更新前备份具体程序文件，失败时回滚；备份及 `restore-map.json` 保存在 `Foldset/Resolve/InstallBackups`。卸载将程序和受管理模板菜单归档，不删除目录，不触及 `UsageReports`、`MoveReports`、`TrashReports`、`ProjectBackups`、模板和其他脚本。
- 预览版可检查状态，但禁止安装和卸载。开发者旧安装脚本保留用于开发，仍会现场编译；它安装后无清单，App 会提示修复。
